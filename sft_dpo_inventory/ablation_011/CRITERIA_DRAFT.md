**진단에서 나온 후보이고, 판정 기준으로 확정하지 않는다.**
- 아래 수치는 E1(V4 선택에 이미 쓴 셋)에서 나왔다(RESULTS.md).

- 같은 모델 안의 표본 변동(sampling)만으로 모델 평균 정답률 sd가 약 1pp 생긴다(V4 0.99, base 1.38).
- 순서 seed 효과는 E1에서 정답률 sd 약 1.6–2.0pp, 올바른 거부율 sd 3.6pp다.
- arm 비교에서 실제로 나온 해로운 변화의 크기:
  - 정답률: −3 ~ −17pp
  - 올바른 거부: −11 ~ −24pp
  - 과잉 거부: +10 ~ +12pp

## 안 1 — 절대 하한(V4 seed 분포 기준)

후보 하나(seed 3개 이상의 평균)가 다음을 모두 만족한다.

| 지표 | 기준 | 근거 |
|---|---|---|
| 정답률 | ≥ 70.5 | V4 평균 − 1 sd |
| 올바른 거부 | ≥ 85.0 | V4 평균 − 1 sd |
| 과잉 거부 | ≤ 3.0 | V4 6 seed 최대 2.66 위 |
| U 표본 | ≤ 20/모델 | |
| wall p95 | ≤ 30초 | |
| 잘림 호출 | ≤ 1% | |

- 장점: 단순하고, seed 하나가 우연히 낮아도 평균으로 흡수한다.
- 단점: E1에 맞춘 수치라 같은 셋으로 고르면 낙관적이다. E1 정답률의 seed 차가 작아 client10k에서 보인 유형별 큰 편차(o43 사례)를 걸러내지 못한다.

## 안 2 — V4와 짝 비교(비열등 한계)

같은 순서 seed 짝으로 후보 − V4를 비교한다. bootstrap(seed 짝·문항 재추출) 95% CI로 다음을 모두 만족한다.

| 지표 | 기준 |
|---|---|
| 정답률 | 하한 > −3pp |
| 올바른 거부 | 하한 > −5pp |
| 과잉 거부 | 상한 < +1.5pp |

- 한계값은 이번 arm 비교에서 해로운 변화가 낸 크기보다 작고, seed sd보다 조금 크게 잡았다.
- 장점: seed 변동을 CI에 넣고, 이번 A1·A2·A3 같은 변화를 모두 잡는다(세 arm 모두 이 기준에서 떨어진다).
- 단점: seed 짝 3개로는 CI가 넓다. 올바른 거부 A2 CI 폭이 32pp였다. 그래서 seed 수가 늘어야 하고, 세 지표를 모두 요구하면 통과가 어렵다.

## 안 3 — 2단계(넓은 셋에서 seed 일관성 + E1 하한)

- 1단계(넓은 셋): client_test_10000 같은 수천 문항 셋에서 seed마다 정답률과 template_group 최저 정답률을 본다.
  - 예: 모든 seed의 정답률 ≥ base + 5pp, 30문항 이상 template_group 중 최저 정답률 ≥ base의 그 그룹 − 20pp.
  - V4 o43(8.8% vs base 89.7%)처럼 seed 하나가 특정 유형을 잃는 것을 잡는다.
- 2단계(E1 또는 새 holdout): 안 1의 과잉 거부 ≤ 3.0과 올바른 거부 ≥ 85.0만 요구한다.
- 장점: E1이 못 보는 유형별 seed 붕괴를 잡는다.
- 단점: 넓은 셋 측정 비용이 크다(10,000문항 × seed). template_group 정의가 셋마다 달라야 할 수 있다. 1단계 수치는 이번에 근거가 client10k 기존 셀뿐이다.
