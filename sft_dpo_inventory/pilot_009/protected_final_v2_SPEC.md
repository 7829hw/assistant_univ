## 6. 검정력 — bootstrap 모의실험(`pilot_009/analysis/power9.py` → `power9.json`)

**방법**:
- 문항 모집단은 pilot_008 셀에서 잡았다.
  - 거부: refusal_dev v1 거부 30(base k=12, P8 다섯 × k=4)과 확장 초안 60(J-rdev2, base k=4, P8 다섯 × k=4)을 합친 90문항의 문항별 올바른 거부율. 모집단 평균 base 26.8%, P8 23.6%, 문항 차 sd 33.6%p.
  - 정답률: 주 셋 151문항의 문항별 정답률(base 75.6%, P8 82.1%).
- 모의 한 번은 다음 순서로 한다.
  1. 문항을 n개 복원 추출한다.
  2. base 참값 p_b를 두고, 후보 참값 = clip(p_b + 문항 차(평균 0으로 맞춤) + s)로 정한다. s는 모집단 평균 차가 Δ가 되게 이분법으로 맞춘다.
  3. 두 모델 각각 k=8 이항 표본을 뽑는다.
  4. 문항 쌍 bootstrap 2,000으로 95% CI를 구한다.
- 모의 2,000번, `numpy.random.default_rng(20261026)`(부분마다 새로).

| 셋 | 참 차이 Δ | 95% 반폭 중앙값(5–95%) | 통과 확률 |
|---|---:|---|---:|
| **거부 50, k=8, 비열등 하한 ≥ −15%p** | 0 | 10.1%p(8.3–11.9) | **0.81** |
| | +10 | 10.3%p | **0.995** |
| | −10 | 9.4%p | **0.19** |
| (참고) 거부 30(1판), 같은 모의 | 0 / +10 / −10 | 12.9%p | 0.61 / 0.95 / 0.15 |
| **답하는 100, k=8**, 우월 하한 > 0 | 0 / +5 / +8 | **7.6%p**(6.6–8.6) | 0.03 / 0.27 / 0.56 |

- 거부 50이면 base 수준 후보(Δ = 0)의 통과 확률은 0.81이다. 1판 30문항은 모의 0.61, 1판 정규 근사로는 0.54였다. −10%p 나쁜 후보는 0.19로 통과한다.
  마진 −15는 그대로 두었다(J-c 유지). Δ = −10 통과 0.19는 "비열등" 마진이 −15라서 생기는 몫이다.
- 정답률 반폭 7.6%p는 1판 120문항(6.2–6.7%p)보다 넓다. 참 +8%p 개선의 검출 확률은 약 0.56이다.
  pilot_007 F-o11 대 base의 protected_final_v1 차이는 +10.7%p였다. 그 크기면 이 셋의 검출 확률은 이보다 높다(Δ = +10은 계산하지 않음).
- 한계:
  - 모집단이 pilot_008 모델(P8)에서 나왔다. pilot_009 후보의 문항 차 분포는 다를 수 있다.
  - 확장 60의 base는 k=4라 문항 참값의 잡음이 크다.
  - P·C 문항(v2 거부의 ⅓)은 refusal_dev에 거의 없어 모집단에 반영되지 않았다.
