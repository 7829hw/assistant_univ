## 3. 판단(지시 C1 기준에 대어)

- **X2 ≠ B1(같은 seed)**: 같은 조건 반복의 평균 차이 3.1%p(구분 안 됨), 첫 호출 원문은 98문항 중 2–3개만 같다. **실행 간 비결정성**이 있고, 그 크기는
  k=4 셀 평균에서 약 ±3%p다(결정 93: vLLM 표본은 seed로 재현되지 않음). B1 − p007의 −6.4%p 중 상당 부분이 이 변동이다.
- **X1 ≈ 75**: X1(73.5%)은 p007(75.0%)과 구분되지 않는다. 가상환경 변경(결정 99)·LoRA 동시 적재로 인한 **환경 변화의 흔적은 없다**.
- **서버 한도 효과**: 두 한도의 8표본씩을 합치면 −4.1%p [−7.3, −1.0]로 경계에 걸린다. 그러나 같은 서버 한도 변경에서 학습 모델 R3a는 0.0%p로 그대로다.
  한도가 계산을 체계적으로 바꾼다면 두 모델 모두에 나타날 가능성이 크므로, **base에만 작은 효과가 있을 가능성을 배제하지 못하지만 근거는 약하다**.
- 결론: B1이 낮은 주원인은 **실행 간 변동(B1이 낮은 쪽 표본)**으로 본다. 환경 변화는 없다. 서버 한도의 작은 효과(base 약 −2~−4%p)는 남는 불확실성이다.

## 4. pilot_005 영향

- pilot_005의 base(p007)와 후보(v1_step467 등)는 같은 16,384 서버 설정·같은 venv 버전 표기에서 쟀다. 후보 셀은 결정 99 뒤(10-15)이고 base는 결정 99 전(10-14)이지만,
  X1(결정 99 뒤, 16,384)이 p007과 구분되지 않으므로 **다른 환경의 base와 비교했다는 근거는 없다**.
- 만약 base를 X1(73.5%)로 바꿔도 v1_step467의 차이는 +11.2 → +12.7%p로 커질 뿐이라 pilot_005 선택·중단 규칙 판정은 뒤집히지 않는다(지시 5절 멈춤 조건 아님).

## 5. pilot_006 base 권고

- 결정 117대로 비교의 base는 17,408 서버 셀이다. **B1과 X2를 합친 k=8(평균 70.2%)을 selection_v2 base로 쓰고**, 표에는 B1·X2를 따로도 적는다.
  단일 k=4 셀(B1 또는 X2)만 쓰면 실행 간 변동(±3%p)이 그대로 기준에 들어간다.
- 더 나은 방법: 세션 3에서 F·P 셀과 **같은 서버 세션·같은 시간대에 base를 한 번 더**(k=4) 재고 B1·X2와 합친다. 이 경우 base는 k=12가 된다(사전 등록에 명시).
- Gate A–E(F 대 P)는 base를 쓰지 않으므로 이 불확실성의 영향을 받지 않는다. arm별 선행 조건(대 base)만 영향을 받는다.
- 참고: 서버 한도 효과를 직접 확인하려면 같은 시간대에 16,384·17,408 base를 번갈아 여러 표본 재야 한다(이번 세션 범위 밖, 제안만).
