## 4. 결론(PLAN 9.6 질문)

### 4.1 HF와 Ollama의 greedy 차이(82 대 70)가 sampling에서도 남는가?

- **base에서는 남지 않는다 — 확인됨.**
  - HF-base 74.0과 Ollama c 74.75·d 75.5의 차이는 +0.75·+1.5이고, CI 위쪽 끝도 5.0·5.5라 12%p 차이와 맞지 않는다.
  - greedy 82는 HF-base sampling 분포 밖(z +2.67)이고 c·d greedy 70은 분포 아래쪽이다. greedy 차이는 한 번씩 뽑힌 값의 차이였다(가능성 있음: greedy가 왜 위·아래로 갔는지는 분리하지 못함).
  - 단, 자체 변환 base Q4(B-conv)는 HF-base보다 6.0 낮다(참고 쌍, CI [−11.25, −0.75]). 공식 Q4(c)는 낮지 않으므로 차이는 Q4 변환 경로에 있다(4.3).
- **최종 모델에서는 남는다 — 확인됨(크기는 5–9%p).**
  - HF-final → e(Q8) −5.5 [−10.25, −0.5], HF-final → Ollama-final(Q4, 참고) −8.5 [−13.75, −3.5].
  - Q8에서도 남으므로 양자화만으로는 설명되지 않는다. adapter 병합·변환이나 실행 경로 쪽 원인은 이 측정으로 분리하지 못했다(미확인).

- 학습 뒤 집계 추가는 세 경로 모두 줄었다(1.2, 참고).

### 4.3 Q4_K_M과 Q8_0의 차이가 잡음보다 큰가?

- **base: 크다 — 확인됨.** B-conv → d +7.5 [2.0, 12.75], 잡음 폭 ±4.89. U는 −3.25 [−7.0, 0.0](경계).

   - (c) 차이가 잡음 폭(k = 4에서 약 ±4.5%p)보다 크면 개선.

   - 여러 쌍을 볼 때 다중 비교를 보정할지도 정해야 한다.
4. **U 기준.**
   - (a) 지금의 "U 순증 ≥ 3"을 k = 1에 그대로 씀. 같은 셀 두 표본 사이에서도 10%에서 걸린다.

   - (c) "순증 ≥ 3"을 k표본 평균에 적용(k = 4 이상에서 잡음 폭 ±2.3–2.7%p 안팎).
5. **운영 경로의 양자화 수준.**
