## 검사 중 지적과 수정

초기 생성기 검사에서는 Git 후보의 과도한 자동 분류, 저장소 보조 범위의 보호 inode 검사, 같은 blob을 다른 경로의 추적으로 오인하는 처리, 링크와 `..` 해석 순서, 제안 Git 파일의 조상 충돌, 스캔 안정성 및 해시 캐시 경계가 지적됐다. 최종 실행 전 수정하고 회귀 테스트를 추가한 뒤 두 코드 검토자가 생성기 검사를 통과시켰다.
