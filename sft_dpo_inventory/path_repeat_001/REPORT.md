# 새 장비 경로 반복 측정 (path_repeat_001)

작성: 2026-10-09. 계획 `PLAN.md`(확정 2026-10-08, 결정 56), 이탈 `PLAN_DEVIATIONS.md`, 수치 `analysis.json`(`analysis.py`로 생성).
이 측정은 경로 진단이다. 업체 100 결과는 평가 전용이며 판정, 기준값(84, 79) 교체, 학습, checkpoint 선택, annotation 후보에 쓰지 않는다(`CLAUDE.md` 8번, 결정 56).

두 경로는 아래처럼 부른다.
- **HF Qwen3-8B (BF16)**: transformers `Qwen/Qwen3-8B@b968826d`, BF16·SDPA, `enable_thinking=True`.
- **Ollama qwen3:8b (Q4_K_M)**: Ollama `qwen3:8b` digest `500a1f06…`, think 미지정(thinking 켜짐).

## 1. 요약

- **질문 1. 기존 greedy 결과는 새 장비에서 재현되지 않았다. [확인됨]**
  - 첫 응답 원문 바이트 일치: HF Qwen3-8B (BF16) **0/100**, Ollama qwen3:8b (Q4_K_M) **30/100**. 계획의 중단 조건(< 50/100)에 두 경로 모두 걸려 멈추고 보고했다. 사용자 결정으로 sampling을 이어 쟀다(`PLAN_DEVIATIONS.md` 2절).
  - grounding_ok: HF Qwen3-8B (BF16) 84 → 79, Ollama qwen3:8b (Q4_K_M) 79 → 82. 순위가 뒤집혔다.
  - 새 장비 greedy에서 두 경로가 갈린 문항은 19개다. 기존 17문항과 겹치는 것은 5개(031 054 059 083 097)뿐이다.
- **질문 2. 기존 17문항 중 체계적 차이는 하나도 없다. 15개는 경계, 2개는 둘 다 안정 정답이다. [확인됨, 분류 규칙 기준]**
  - 17문항 모두 |k_HF − k_Ollama| ≤ 3이다. 기존 greedy에서 Ollama qwen3:8b (Q4_K_M)만 맞힌 6문항은 sampling에서 모두 k_HF ≥ k_Ollama였다. greedy가 보여 준 방향이 sampling에서 유지되지 않는다.
  - 따라서 17문항의 차이는 경계 문항이 경로·장비마다 다르게 뒤집힌 것으로 본다. [가능성 있음] 5회 표본이라 k 해상도가 낮다.
- **sampling 조건에서는 경로 간 차이가 작지만 있다. [확인됨, sampling 조건 한정]**
  - 회차별 grounding_ok 평균: HF Qwen3-8B (BF16) 83.6(82–85), Ollama qwen3:8b (Q4_K_M) 78.2(77–79). 범위가 겹치지 않는다.
  - 문항별 정답률 차이 평균 +0.054(HF 쪽이 높음), 95% CI [0.012, 0.098], paired permutation p = 0.023.
  - 체계적 차이 문항은 084·089 두 개이고 둘 다 HF 5/5, Ollama 1/5다. 두 문항 모두 greedy에서는 양쪽 장비·양쪽 경로가 맞혔다.
- **greedy 하나로는 경로 값이 sampling 범위를 벗어날 만큼 흔들린다. [확인됨]** 새 장비 greedy는 HF 79(sampling 범위 82–85 아래), Ollama 82(77–79 위)다. 기존 greedy 84·79는 범위 안에 있었다.
- **greedy에서만 틀리는 문항이 있다. [확인됨]** 059(Ollama), 083(HF)은 그 경로 greedy가 두 장비 모두 틀렸으나 sampling은 양쪽 5/5다. 054는 반대로 HF greedy가 두 장비 모두 맞혔으나 sampling은 0/5다.

## 6. 17문항 분석: 체계적 차이인가, 경계인가

| 분류 | 문항 |
|---|---|

- **17문항 중 체계적 차이는 없다. [확인됨]** |k_HF − k_Ollama|의 최댓값은 3(013: 3 대 0, 074: 4 대 1)이다.
- **기존 greedy의 방향은 sampling에서 유지되지 않는다. [확인됨]**
  - 기존 greedy에서 HF Qwen3-8B (BF16)만 맞힌 11문항(008 013 041 047 054 059 060 072 080 097 100): k_HF − k_Ollama가 양수 5, 0이 2, 음수 4.

- **새 장비 greedy에서 17문항 중 12문항은 두 경로가 같은 판정이다. [확인됨]** 갈림이 이어진 5문항 중 059·083은 sampling 5/5 대 5/5이고, 031·054·097은 경계다.
- **059·083은 greedy 특유의 오답이다. [확인됨]** 059는 Ollama qwen3:8b (Q4_K_M) greedy가, 083은 HF Qwen3-8B (BF16) greedy가 두 장비에서 모두 틀렸다. 같은 경로의 sampling은 5/5다. greedy 경로 하나가 틀린 답 쪽으로 고정된 경우이며, 경로 능력의 차이로 읽지 않는다.
