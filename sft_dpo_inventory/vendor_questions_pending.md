# 업체에 물을 질문(대기)

업체에 아직 묻지 않은 질문을 모은다. 답을 받으면 답과 날짜를 적고, 계약·코드 변경은 따로 결정으로 남긴다.

## 1. 실차 구간 건수를 요일(dayofweek)로 묶을 수 있는가 (결정 67, 2026-10-09)

- 현재 상태:
  - 도구 명세에서 `get_trip_count`의 `dimension` 허용값에 dayofweek가 없다.
  - 그래서 합성 단계(`operator_mapping._check_param_contract`)가 `INVALID_PARAM_VALUE`로 멈춘다.
  - 장소 표기와는 무관하다.
- 질문: 실제 도구가 실차 구간 건수를 요일별로 묶어 돌려줄 수 있는가? 있다면 파라미터 이름과 값은 무엇인가?
- 근거: `conversion_diag/CANONICAL_BOTH.md` 3절.

## 2. 장소보다 같거나 넓은 단위로 묶을 수 있는가 (결정 67, 2026-10-09)

- 현재 상태: mock 도구가 `UNSUPPORTED_COMBINATION`을 돌려준다("지정한 승하차 scope와 dimension에 해당하는 후보가 없습니다").
  - 해당 경우: 읍면동 장소를 시군구·시도로 묶을 때, 시군구 장소를 시도로 묶을 때.
  - 일부 h3도 mock 고정 자료에 후보가 없어 멈춘다.
  - 호출은 만들어진 뒤 실행 단계에서 멈춘다.
- 질문:
  - 실제 도구에서 같은 조합(예: 대구 중구 동인동 scope를 시군구 단위로 묶기)의 결과는 무엇인가? 한 행인가, 오류인가?
  - h3 묶음은 어떤 장소 단위에서 지원하는가?
- 근거: `conversion_diag/CANONICAL_BOTH.md` 3절. mock 고정 자료의 결과이므로, 실제 도구에서도 같은지는 모른다.
