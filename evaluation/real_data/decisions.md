# 실제 자료 검증 전에 정해야 할 해석 (결정표)

작성: 2026-10-05(grounding_v15).
- 업체나 서비스 담당자가 정해야 할 의미를 여기서 확정하지 않는다.
- 사람 검토 없는 합성 라벨(grounding_v12 측정값 대조·최종 셋)을 업체 정답으로 바꾸지 않는다.
- 각 항목의 "현재 정책"은 지금 코드와 라벨이 따르는 동작일 뿐이며, 의미가 맞다는 근거가 아니다.

**결정이 나오면 할 일:**
- 결정마다 근거(문서·회의록 위치)를 이 표에 적는다.
- 그 결정에 기대는 라벨은 결정 근거를 `label_basis`(아래 입력 형식)에 연결한다.
- 합성 셋의 기존 라벨을 바꿀 때는 이전 결과를 보존하고, 모든 비교 대상에 같이 적용한다(grounding_v13 label_audit의 원칙).

**이미 정리된 계약 미확인 항목(중복하지 않음):**
- TIMS 쪽 미확인 항목은 `evaluation/design/tims_lowering_contract.md` 2절과 `geoflow/tims_contract.py`에 이미 있다.
  - 주 시작일, 부분 구간, 빈 구간, null 반환, 상대 날짜 기준 시각, weekday·weekend·holiday 기간.
  - 날짜 범위 양 끝 포함, avg의 분모, 날짜 귀속.
- 실제 TIMS 응답으로 확인할 때 위 항목도 같은 입력 형식으로 기록한다.
