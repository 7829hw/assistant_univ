1. 모델 원출력: 형식 유효(grounding 계약 통과), 의미 정확(정답 grounding과 같은가)

3. 조건 보존 뒤(날짜·택시 유형·운행 상태, 장소 근거)
4. (v2 전체 보정 코드에만) 의미 재해석 뒤
5. 최종 grounding(재질의 포함)과 최종 Tool 호출·답변
6. 정답 grounding → 실행기(`gold`)와 정답 grounding → 보정 계층(`gold-audit`)은 따로 센다.
7. 층마다 앞 층 대비 고침·훼손, 호출(계획·재질의·실패), 지연(중앙값·p90·최대·합계·전체 경과)
