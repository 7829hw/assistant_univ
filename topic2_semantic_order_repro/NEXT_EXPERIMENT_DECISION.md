# 다음 연구 방향 결정 (Stage 5, PLAN 7절 사전 규칙 적용)

## 규칙 적용
- 방향 A(재현성/분산): 재학습 SD(전체) 2.43pp ≥ 1pp **충족**, T1 재학습 SD 22.63pp > |T1 Arm 효과| 18.13pp **충족** → **권고**.
- 방향 B(LR-aware 스케줄링): 근거 없음 → **가설**. LR 가중 노출은 B에서 오히려 더 크고(21.7% vs 15.0%), 노출 통계가 seed별 T1 결과를 설명하지 못한다.
- 방향 C(실행 의미 서명): **가설**. 서명에 fare가 없다는 사실은 확인됐으나 이것이 원인이라는 검정 가능한 증거는 이번 데이터에 없다.
- 방향 D(커버리지): **가설**. V4에 fare 직접 기록이 거의 없다는 사실은 확인됐지만, 커버리지를 늘려 T1이 개선되는지는 학습 없이 알 수 없고 승인되지 않은 데이터 사용이 필요하다.

## 결정
**방향 A를 권고한다.** 새 스케줄러나 C/D 학습 arm은 근거가 없어 제안하지 않으며 자동 진행하지 않는다. 사용자 결정 사항:
1. 이후 순서·데이터 비교는 arm·seed당 ≥ 3 run을 기본으로 하고 보고에 재학습 SD를 병기한다(이번 설계의 MDE 약 17pp이므로, 수 pp 효과를 보려면 seed·run 수가 크게 늘거나 평가 문항·k를 늘려야 함 — 비용은 학습 1회 ≈ 3.2 GPU-시간).
2. 잡음 원천 분리(학습 vs 평가 샘플링)가 필요하면 같은 체크포인트를 k>1로 평가하는 값싼 사전 실험을 먼저 한다(GPU 학습 불필요).
3. 어떤 방향이든 H-final은 봉인 유지.

이 결정은 연구 방향이며 새 방법의 우수성에 대한 주장이 아니다.
