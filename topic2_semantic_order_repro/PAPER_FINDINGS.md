# 논문에서 주장할 수 있는 것 / 없는 것

## 주장할 수 있다 (이 데이터가 직접 보여준다)
1. **재학습 변동성이 크다.** 같은 데이터·순서·설정을 다시 학습하면 H-dev 전체 정확도 SD 2.4pp, T1 SD 22.6pp(seed·arm 평균 SD 1–4pp, T1 최대 29–33pp)이며 문항 수준에서 재학습만으로 전체의 14%, T1의 37%가 달라진다. 단일 학습 run 비교는 이 잡음 위에서 해석해야 한다.
2. **단일 run의 seed별 arm 효과는 신뢰하기 어렵다.** r1 단일 run의 B−A(−15.1/−10.8/+4.1)가 3 run 평균(−8.9/−6.2/+1.7)에서 크게 줄었다.
3. **T1(fare) 붕괴는 B 고유가 아니라 재학습·seed에 따라 나타나는 불안정 모드이며 B에서 더 자주 관찰됐다**(붕괴 run 6/9 vs 3/9, 유의하지 않음). 실패 유형은 대부분 지역 조회(place lookup) 누락과 refusal이다.
4. **현재 설계(seed 3, run 3)로는 Semantic-balanced와 O4′의 차이를 구분할 수 없다**(B−A −4.44pp, 95% CI [−10.18, +1.83]; 최소 검출 효과 약 17pp). 이는 "차이가 없다"가 아니다.
5. 기존 결론 유지: 사전 등록 S1–S4가 CT10K에서 실패했고 H1은 지지되지 않았다. 이번 결과는 이를 뒤집지 않는다(Q3 참고).
6. B의 refusal 증가(1.7→4.2%)와 worst-group 하락(30.3→16.2, 평균)은 arm 평균에서 일관되나 seed 3개에 대한 기술 통계다.
7. 진단 사실: 학습 서명에 fare·`get_trip_metrics`가 없고(SIGNATURE_AUDIT), B 순서는 의미 균형 외에 teacher 스타일·LR 위상 노출을 바꾼다(ORDER_EXPOSURE_ANALYSIS).

## 주장할 수 없다
- Semantic-balanced가 O4′보다 나쁘다 / 같다 / 좋다 (구분 불가).
- LR 가중 노출, 대조 teacher 이웃, 서명 불일치 중 어느 것이 T1 실패의 원인이라는 것(모두 inconclusive).
- seed 3개에서 나온 순서 효과·상호작용 크기의 일반화(자유도 2).
- H-final 결과·CT10K 재현 수치(이번에 평가하지 않음).
