## 함께 보고(등록된 보조·탐색)

- X3a 지표 3(taxi_type 대체율, 누락 계획 중): −31.6%p, 16 run 모두 감소(누락이 있는 16 run). 방출률은 그대로인데, 누락한 계획이 taxi_type을 덜 쓴다.
- X3a 지표 1: +8.2%p, 18 run 모두 증가(p = 7.6e-6). 기준에 없던 방향이며 기술로만 적는다. B arm에서 특히 크다(15.9% → 29.9%).
- X3b 지표 2(탐색): **+39.9%p, 17 run 증가·0 감소(1 run 동률), p = 1.5e-5.** arm 평균 A 71.0% → 99.2%, B 46.8% → 98.3%.
  "요금"을 "수입"으로만 바꾸면 거의 모든 출력이 LOCATION을 낸다. 탐색 결과이고, (b)는 측정값의 뜻이 바뀌므로 정확도는 재지 않았다.
- base: 세 조건 모두 분석 양식 출력이 0건(전부 "기타")이라 지표 1–3이 정의되지 않는다. 모든 출력 기준 LOCATION 비율은 원래 99.3–100%,
  탐침 a 97.3%, 탐침 b 98.6–99.3%.

## 한계

- 원래 셀은 다른 시각·GPU에서 쟀다. 같은 어댑터 재평가에서도 문항 불일치가 7.5–11.4% 있었다(스크립트 [4]). 탐침 차이에는 이 잡음이 섞인다.
- 탐침 b의 큰 방출률 변화는 "요금"이라는 단어 자체인지, "수입"이 학습 데이터의 다른 양식과 이어지는지 이 설계로는 가르지 못한다.
