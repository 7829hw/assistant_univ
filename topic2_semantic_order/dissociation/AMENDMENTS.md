## 1. X2·중간 체크포인트·B안 계산 방법: 트리 계산 (2026-11-17, 지표·기준 변경 아님)

- 무엇: X1(최종 18 자기 풀이)은 `x12_score.py`(토큰화 경로마다 token 하나짜리 forward, 문항당 평균 약 111회)로 계산했다.
  같은 방식이면 X2(18×18, 43,380행) 등에 GPU 한 장 기준 30시간이 넘는다. 그래서 나머지는 `x12_tree.py`로 계산한다.
- 같은 값인 이유: 같은 경로 나무를 깊이별로 펼쳐 한 깊이의 마디를 forward 한 번에 넣고, 4D 마스크로 각 token이 (문항 접두 + 자기 조상)만 보게 한다.
  위치 id·가지치기 규칙(PRUNE −40)·세 목표 문자열은 그대로다. Δ와 보조 지표(logp_loc_given_cont)의 정의는 바뀌지 않는다.
- 확인: CPU 단위 테스트(`test_x12_tree.py`, 가짜 분포에서 순차 계산과 소수 12자리 일치, 가지치기 포함).
  GPU 검증은 최종 18 어댑터 자기 풀이 앞 12건(216행)을 트리로 다시 계산해 X1과 대조한다(`tree_check.py`).
  기준(결과 보기 전에 정함): 겹침 ≥ 100, |ΔΔ| 최대 ≤ 0.10, 중앙값 ≤ 0.02, |Δ| ≥ 0.1인 행의 부호 100% 일치, 보조 지표 |차| 최대 ≤ 0.10.
  못 넘으면 X2를 시작하지 않고 보고한다.
- X2의 대각(자기 풀이) 칸도 트리로 다시 계산해 행렬 전체를 한 방법으로 맞춘다. AUC 게이트와 X1-H는 X1(순차) 값으로 판정한다.
- 일정: GPU 0·2에서 X2 등을 X4보다 먼저 돌린다(X4 쌍 1·3·4·6·7·9가 그만큼 늦어진다). GPU 1의 X4 쌍 2는 이미 시작해 그대로 둔다.
- 승인: 사용자가 2026-11-17 "순서 변경 승인, 계속 진행해"로 X2를 X4보다 먼저 돌리는 순서를 승인했다.
