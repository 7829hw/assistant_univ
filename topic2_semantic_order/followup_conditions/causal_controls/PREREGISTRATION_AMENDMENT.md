# Integration amendment for E5–E7

Dated 2026-11-15 KST. The original causal-controls protocol is the file and SHA in commit `abff9048b061b15d4bd26c0bac4d9b26847b050d`. At amendment drafting, no E5–E7 GPU training or checkpoint evaluation receipts exist. E1/E2 are already running and some of their results have been observed. This amendment applies prospectively only to the unobserved E5–E7 outcomes. It does not alter E0–E4, S1–S4, the prior primary metrics, contrasts, tests, Holm family or exposure thresholds. The branch commit introducing this document fixes its text.

The failed E5 factorial matching and successful E6/E7 schedule audits were already observed on CPU. These are feasibility results. For the frozen E5 candidates, all three factorial estimands remain exploratory under the original eligibility gates. Keep their point estimates and individual paired differences if the arms are subsequently authorized and measured. Never promote them to the primary testing family. The simple S1T0 − S0T0 contrast is a secondary descriptive estimate with its own exposure audit. E6 and E7 retain the registered collapse-count contrasts and all eight order seeds crossed with both training seeds.

Alongside the registered order-block sign-flip test and t interval, report two secondary 95% percentile intervals per estimable contrast. Both use 10,000 draws and separate NumPy generators spawned from SeedSequence(20261115). The run-only bootstrap resamples order blocks, then resamples the paired training seeds within each drawn order block, on fixed CT10K items. The hierarchical bootstrap also resamples whole CT10K template clusters, using the same cluster weights for every arm and run within a replicate. The same run draws are used in the two bootstraps independently of cluster sampling. Retain full-dataset group eligibility, omit groups with zero drawn support in a replicate, and recompute Collapse20 from the frozen base under the draw. Report the variability of paired differences across the two training seeds within each order block. The intervals are descriptive, including for E5 if measured despite failed matching. They do not change the multiplicity decision. At eight order blocks, the smallest nonzero two-sided exact p-value is 2/256. The most stringent Holm threshold is .05/6. Both the finite resolution and the sign-symmetry assumption limit inference.

At each checkpoint, use the original eligible fine, coarse, T1 and T5 masks. Report the two base→SFT transitions as both fractional counts and rates divided by the size of the relevant base population. Base correctness is the average of the saved base draws, so fractional counts are expected. Report accuracy, collapse, refusal and silent wrong on the unchanged scorer, and descriptive within-run changes across the four checkpoints.

The expanded tool-grounding taxonomy is a post-hoc diagnostic for already observed results. It identifies missing executed lookups using gold only for evaluation. Model plan omissions, downstream loss of a correct place plan, other failures and ambiguous cases use the decision rules in `TAXONOMY.md`. Existing E1/E2 intermediate checkpoints can be inventoried using CPU I/O. Evaluating them requires additional scope because the current manifests cover epoch-end adapters. Never retrain to replace a missing intermediate checkpoint. Keep any supplementary checkpoint results apart from the frozen E1/E2 final comparisons.

GPU stopping rules are technical and predate outcomes. Skip a run when any required device, authorization, SHA, preservation or comparability gate fails. Do not replace a seed or choose checkpoints by performance. Reuse the existing rule of at most one same-cell evaluation retry for excessive truncation or server errors. Preserve both attempts and mark residual failures. Read or execute only CT10K/H-dev and existing approved E1 diagnostics. E4 remains preparation-only.
